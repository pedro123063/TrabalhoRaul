1. Instalar todas as dependências python por meio de pip (verificar `requirements.txt`)

2. Instalar ollama

3. Por meio do cmd, rodar comando: `ollama run deepseek-r1:1.5b`

4. Obter chave de API google por meio do aistudio

5. Colar chave no campo correspondente do file `core\promptSender.py` em `API_KEY_GEMINI`

6. Rodar "run all" no notebook `main.ipynb`

7. Ler impressões do notebook para respostas e tempo de resposta de cada llm

8. Buscar tabelas de resultado na pasta `resultados_tabelas`
